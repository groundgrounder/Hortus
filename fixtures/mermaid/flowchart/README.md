# Flowchart regression samples

The original thirteen named samples from `flowchart-spike` are synthetic public fixtures, licensed under MIT OR Apache-2.0. `forest.mmd` and `identity.mmd` are dedicated CC0-1.0 samples. Keep their notices when copying them.

`subgraphs.mmd` is the nested-container negative case; only top-level containers are supported. `subgraphs-top-level.mmd` covers container and member layout, visible/invisible endpoints, basic CSS properties and UTF-8 ranges. `invisible-links.mmd` covers ordinary-node `~~~` ordering and a cycle. `unsupported.mmd` remains a ranged diagnostic case. The remaining samples exercise the product parser and native scene renderer. Private note content must never be added here.
