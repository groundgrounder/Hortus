# Flowchart regression samples

The thirteen named samples from `flowchart-spike` are synthetic public fixtures, licensed under MIT OR Apache-2.0. `forest.mmd` and `identity.mmd` are dedicated CC0-1.0 samples. Keep their notices when copying them.

`subgraphs.mmd` and `unsupported.mmd` are negative cases. `class-styles.mmd` also exercises CSS properties beyond basic hex fill/stroke and must return a ranged diagnostic. The remaining samples exercise the product parser and native scene renderer. Private note content must never be added here.
